# n8n Railway (v1.41.0+)

Este repositório permite rodar o n8n com suporte ao AI Agent (chat) no Railway, usando Docker.

## 🚀 Como usar

1. Clone este repositório ou importe para seu GitHub
2. No Railway, clique em "New Project" > "Deploy from GitHub Repo"
3. Escolha este repositório
4. Após o deploy, o n8n estará disponível com autenticação básica
